# edit-ng

edit-ng is a text editor based on [microsoft/edit](https://www.github.com/microsoft/edit).

## Installation
Install the latest version of edit-ng from [GitHub Releases](https://github.com/ashferndotcom/edit-ng/releases/tag/v0.1.0) and run the command below:
```bash
chmod +x ~/Downloads/edit-ng 
```
This will create an executable from the downloaded program (you can run it from the original .bin.)

## Usage
Now, open the executable in the terminal by executing:

```bash
cd ~/Downloads
./edit-ng
```
This will open edit-ng.
